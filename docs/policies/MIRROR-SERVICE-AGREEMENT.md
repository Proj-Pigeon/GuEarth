# 咕咕地球镜像服务使用协议

**更新日期：2026年11月17日**

本《咕咕地球镜像服务使用协议》（以下简称“本协议”）由咕咕地球（GuEarth）开源项目协作组与奈索星联（NexaOrion）团队（以下合称“服务提供方”）共同制定，适用于用户通过咕咕地球客户端访问与使用海外地理教学资源镜像加速服务（以下简称“本镜像服务”）的全部行为。

## 1. 服务主体与协议效力

咕咕地球项目组与奈索星联团队均为非注册法人性质的技术协作组织。本镜像服务系双方基于公益与教育互助目的，面向中华人民共和国大陆地区（不含港澳台地区，以下简称“中国大陆”）用户提供的边缘缓存加速服务。

在启用本镜像服务前，您应当完整阅读、充分理解并勾选同意本协议及《可接受使用政策》。若您不同意本协议或《可接受使用政策》的任何条款，请点击 “不需要” 或保持本镜像服务处于关闭状态，客户端将继续以直连方式访问各原始数据源。

## 2. 服务内容与技术机制

本镜像服务仅针对咕咕地球客户端地理教学所依赖的公开海外地理与科普数据源提供边缘节点缓存与反向代理加速，具体涵盖：

- OpenStreetMap 标准道路瓦片；
- Esri World Imagery 全球卫星影像瓦片；
- OpenTopoMap 全球地形晕渲瓦片；
- NASA GIBS（VIIRS Black Marble）全球夜间灯光遥感瓦片；
- ArcGIS WorldElevation3D 全球三维地形元数据与高程数据；
- 美国地质调查局（USGS）全球 4.5 级以上近期地震目录；
- `models.dev` 开源人工智能模型能力元数据目录。

## 3. 测绘与地理信息合规声明

本镜像服务严格遵守《中华人民共和国测绘法》《地图管理条例》及相关地理信息管理规定：

- 本镜像服务所缓存与转发的海外公开底图、遥感影像、三维高程及地震目录，仅被允许用于地理课堂教学演示、自然地理规律探究及科普学习参考，不构成中华人民共和国法定标准地图，亦不作为国界、行政区域界线、领土主权或不动产权属的法律依据；
- 咕咕地球客户端内置的中国省级行政区划专题数据独立采用合规审定数据源，与海外公开瓦片源相互分离；
- 用户严禁利用本镜像服务从事任何未经批准的测绘活动，严禁采集、处理、标注、存储或传输涉及国家秘密、军事设施、关键基础设施及其他法律法规禁止公开的地理坐标与空间数据；
- 用户不得使用本镜像服务制作、导出、截图发表或公开传播任何损害国家主权、安全、领土完整和国家版图尊严的“问题地图”或违法违规标注内容。

## 4. 用户授权与使用边界

在遵守中国大陆法律法规、本协议及《可接受使用政策》的前提下，服务提供方授予您一项个人的、非排他的、不可转让、不可分许可且可随时撤销的有限使用许可，仅允许您通过官方未经篡改的咕咕地球桌面客户端在正常浏览、教学实验与录制场景下调用本镜像服务。

您不得将本镜像服务的接口地址从客户端中剥离并用于任何第三方软件、网页、脚本、地图引擎、数据爬虫或商业系统。

## 5. 网络日志、数据安全与个人信息保护

服务提供方严格遵守《中华人民共和国网络安全法》《中华人民共和国数据安全法》及《中华人民共和国个人信息保护法》，遵循最小必要与透明原则处理网络请求数据：

- 当您启用本镜像服务时，边缘函数节点仅接收并处理完成 HTTP 瓦片与数据分发所必需的基础网络信息，包括请求客户端 IP 地址、请求时间戳、请求路径、`User-Agent` 标识及标准缓存校验头；
- 本镜像服务不要求、不收集、不存储您的个人身份信息、账号密码、高德/百度/和风天气 API 密钥、AI 服务商密钥、AI 聊天记录、本地标注文件或教学场景数据；
- 边缘节点产生的访问日志与安全审计记录仅用于缓存命中统计、故障排查、抵御拒绝服务攻击（DDoS/CC）及调查违反《可接受使用政策》的滥用行为，并按边缘计算平台及适用法律规定的期限自动轮转与销毁。

## 6. 知识产权与第三方数据源归属

本镜像服务所传输的各类地理瓦片与科学数据集的著作权、数据库权利及相关知识产权均归属于各原始上游提供方。

本镜像服务仅作透明缓存加速，不改变任何原始数据的许可协议。您在使用相关地图画面、遥感影像或教学视频时，应依法保留相应的数据来源署名（Credit/Attribution）。

## 7. 免责声明与服务变更、中止

鉴于本镜像服务系无偿提供的公益教学辅助设施，在适用法律允许的最大范围内：

- 本镜像服务按“现状（AS IS）”与“可获得（AS AVAILABLE）”状态提供，服务提供方不对镜像服务的永久可用性、不间断性、特定速率、零延迟或上游数据的绝对准确性作出任何明示或暗示的担保；

本协议的订立、生效、解释、履行及争议解决均适用中华人民共和国大陆地区法律（不含冲突法规则）。
