# 可接受使用政策（Acceptable Use Policy）

**更新日期：2026年11月17日**

本《可接受使用政策》（Acceptable Use Policy，以下简称“本政策”）旨在明确咕咕地球（GuEarth）及奈索星联（NexaOrion）海外资源镜像服务的使用边界，保护广大师生用户、咕咕地球项目组、奈索星联团队、上游公共地理数据平台及边缘网络基础设施的安全与公平访问秩序

## 1. 目的与适用范围

本政策适用于访问或使用咕咕地球客户端、镜像代理服务、更新服务、在线数据集接口及项目组或奈索星联团队运营的其他相关网络资源的所有用户与设备。

## 2. 允许的使用方式

在全面遵守中国大陆法律法规、上游数据源条款、《咕咕地球镜像服务使用协议》及本政策的前提下，您可以：

- 在官方咕咕地球桌面客户端内开启镜像服务，用于日常地理教学演示、课堂互动、课后自学及自然与人文地理实验；
- 在客户端正常交互频率下浏览道路底图、卫星影像、地形晕渲、夜光遥感、三维地形及地震分布数据；
- 使用客户端内置的本地瓦片缓存功能与教学场景录制功能，在合理范围内预热并生成教学演示视频；
- 在使用 AI 模型导入功能时，通过镜像节点查询公开的模型上下文窗口与模态元数据；
- 在事先获得项目组与奈索星联团队书面授权的情况下，开展合规的教学科研合作或安全性测试。

## 3. 核心合规要求

使用本镜像服务及相关功能时，您必须：

- 严格遵守《中华人民共和国网络安全法》《中华人民共和国数据安全法》《中华人民共和国个人信息保护法》《中华人民共和国测绘法》《地图管理条例》及《互联网信息服务管理办法》等法律法规；
- 尊重 OpenStreetMap、Esri、OpenTopoMap、NASA GIBS、USGS 等上游平台及其他咕咕地球用户的公平访问机会；
- 保持正常的客户端交互请求速率，遵守边缘节点与客户端内置的并发控制、缓存策略及退避机制；
- 当发现自身设备、脚本或网络环境出现异常高频请求或故障死循环时，立即停止相关操作并关闭镜像开关；
- 配合服务提供方针对流量滥用、安全事件或合规问题的合理核查。

## 4. 禁止的测绘与地理信息违规行为

您不得利用咕咕地球客户端或本镜像服务从事下列任何与测绘、国家版图或地理信息安全相关的违法违规行为：

- 未经自然资源及测绘主管部门依法批准，擅自利用本软件或镜像数据从事测绘活动或编制出版地图；
- 在地球视图中标注、绘制、导入、存储、截图或传播任何涉及军事禁区、国防设施、保密单位、关键基础设施或其他涉密地理目标的位置与属性信息；
- 篡改、歪曲或刻意错误标示中华人民共和国国界线、海岸线、岛屿归属、重要地理信息数据及地名，制作或传播任何损害国家主权、安全、领土完整和国家版图尊严的“问题地图”；
- 利用三维高程采样、剖面分析或遥感影像功能对国家法律法规禁止测绘或禁止高精探测的区域进行针对性数据采集与导出。

## 5. 禁止的请求滥用与风控规避行为

为保障公益边缘节点的稳定运行与上游平台的合规回源，您严禁实施下列请求滥用或规避风控的行为：

- 以超出正常人工操作或正常课堂教学所需的速率向镜像服务或上游服务发送请求，导致边缘节点、回源链路或上游服务器过载、降级或拒绝服务；
- 使用爬虫程序、批量下载工具（如瓦片抓取器、全量离线包下载脚本）、自动化脚本或多进程并发工具，按经纬度网格或缩放层级批量遍历、拖拽镜像瓦片与地形数据；
- 修改、移除、绕过或刻意忽略客户端与边缘函数的缩放层级上限、超时退避或本地缓存机制；
- 通过多 IP 轮询、代理池、伪造请求头或其他技术手段规避边缘节点的速率限制与访问控制；
- 在未经服务提供方及目标系统所有者明确书面授权的情况下，对镜像服务及其关联基础设施进行压力测试、容量探测、漏洞扫描或模糊测试。

## 6. 禁止的网络、节点与代理越权行为

您不得对本镜像服务的网络架构与代理机制实施任何越权或非预期调用：

- 尝试利用镜像路径拼接、参数注入、宿主重写或协议转换等手段访问内网地址、云服务商元数据端点（Metadata Endpoint）、受限端口或白名单之外的任何目标；
- 将镜像服务嵌入第三方网站、小程序、移动应用、商业 GIS 系统、开源分支或其他非官方构建版本中作为公共图床或免费瓦片后端；
- 在局域网或公网架设二次转发服务，将本镜像服务包装为对外提供的地图 API 或数据订阅接口；
- 干扰或破坏边缘节点的缓存一致性、健康检查、TLS 握手或 DNS 解析。

## 7. 禁止的安全与完整性破坏行为

除适用法律明确允许、开源许可证授权或事先获得项目组书面同意外，您不得：

- 绕过、篡改或禁用客户端中的协议确认弹窗、合规提示、更新哈希校验（SHA-256）或安全沙箱机制；
- 挖掘、利用、公开散布或隐瞒软件及镜像服务的安全漏洞以实施破坏、窃取配额或牟取不当利益；
- 上传、注入、传播或执行任何计算机病毒、木马、勒索软件、后门或破坏性代码；
- 删除、遮挡、伪造客户端与镜像数据中的版权署名、开源许可证声明、来源标识或合规警示；
- 冒充咕咕地球项目组、奈索星联（NexaOrion）团队、官方服务或团队成员，或使用项目名称、域名、标识进行钓鱼、欺诈或误导性宣传。

> 开展善意安全研究的人员，必须事先通过官方渠道取得书面授权，并严格在约定范围、时间窗口与负责任披露（Responsible Disclosure）规范内进行，严禁影响正常用户体验或消耗大量回源配额。

## 8. 禁止的违法、侵权与有害内容

您不得结合本镜像服务或客户端绘制、录制、存储、分享或传播含有下列性质的内容：

- 反对宪法所确定的基本原则，危害国家安全，泄露国家秘密，颠覆国家政权，破坏国家统一的；
- 损害国家荣誉和利益，歪曲、丑化、亵渎、否定英雄烈士事迹和精神，或煽动民族仇恨、民族歧视的；
- 侵犯他人著作权、商标权、商业秘密、肖像权、隐私权、个人信息权益或其他合法权益的；
- 散布谣言、虚假灾情/地震预警信息、欺诈、诽谤、侮辱、恐吓、淫秽色情、赌博、暴力或教唆违法犯罪的；
- 误导公众认为您的个人作品、课程或言论获得了咕咕地球项目组、奈索星联团队或上游数据机构（如 NASA、USGS、Esri）的官方背书。

## 9. 商业用途限制

本镜像服务系纯公益教学基础设施。未经咕咕地球项目组与奈索星联团队事先书面授权，您不得：

- 出售、出租、转售、分许可或以收费代装、收费加速包、VIP 线路等名义向他人提供本镜像服务；
- 将本镜像服务用于商业培训机构大规模并发部署、商业展览展示、商业遥感分析或收费软件后端；
- 利用咕咕地球或奈索星联的名义进行商业招揽、众筹募资、广告引流或作出任何商业承诺；
- 将项目组或奈索星联团队成员表述为您的商业合伙人、雇员、代理人或担保方。

> 咕咕地球客户端源码所适用的开源许可证赋予您的合法权利不受影响，但任何对线上镜像服务节点的调用均须严格遵守本政策的非商业与反滥用限制。

## 10. 监测、限流与处置措施

在适用法律允许的范围内，咕咕地球项目组与奈索星联团队有权基于边缘节点访问日志、异常流量告警、上游反馈及投诉举报对疑似违规行为进行核查，并视情节严重程度、影响范围与主观恶意采取一项或多项处置措施（无需事先通知）：

- 对异常请求实施速率限制（Rate Limiting）、连接并发限制、返回 `400`/`403`/`429` 状态码或临时冷却；
- 封禁违规 IP 地址、IP 段、自治系统（ASN）或异常客户端指纹对镜像节点的访问权限；
- 暂停、缩减或关停特定路由的镜像缓存与回源功能；
- 固定并保全异常访问日志与违法违规证据，依法向权利人、上游平台、电信主管部门、测绘主管部门或公安网安等执法机关报告并配合调查；
- 依法追究违规行为人的民事侵权责任或行政、刑事法律责任。

## 11. 滥用举报与安全问题反馈

如您发现任何针对本镜像服务的恶意抓取、网络攻击、测绘违规、侵权滥用或安全漏洞，欢迎通过咕咕地球 GitHub 仓库（`https://github.com/Proj-Pigeon/GuEarth`）Issue / Security Advisory 渠道向我们反馈。

提交反馈时，请尽可能提供相关的请求 URL 或路径、发生时间戳、复现步骤、现象描述及您的联系方式。出于数据安全与隐私保护考虑，请勿在公开 Issue 或初次报告中附带任何个人 API 密钥、身份证明文件或敏感个人信息。

## 12. 政策修订与生效

咕咕地球项目组与奈索星联团队有权根据中华人民共和国大陆地区法律法规变更、监管指导意见及边缘服务运行情况适时修订本政策，并在客户端内公布更新版本与生效日期。

本政策修订后，您在客户端启用或继续使用本镜像服务，即表示您已阅读、理解并同意接受修订后的《可接受使用政策》约束。
