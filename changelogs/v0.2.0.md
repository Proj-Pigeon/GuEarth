# v0.2.0 更新日志

![v0.2.0 version cover](https://static.project-pigeon.com/update/v0.2-cover-narrow.png)

## 新功能

- **新增遥测，日志更齐全**：在发生错误时，双渠道同步上报错误日志和 replays，为开发人员提供更全面的日志信息。此选项默认开启，可在 `设置 - 隐私` 内关闭。
- **新增“隐私”设置**：保护用户隐私是我们的使命，因此我们默认仅开启错误日志收集功能，剩余不必要遥测数据不会自动收集并上传。用户可自行开关各项隐私设置。
- **全新 Agent 底层架构**：我们在 EOQ 教学智能体中创新性地引入了 `HawDB` 作为上下文引擎、知识库框架，节省上下文浪费和 token 支出。
- **智能镜像代理服务**：目前提供 `EdgeOne` 和 `CloudFlare` 双源镜像服务，在开启时自动测速并使用质量更佳的服务源。

## 修复

- 修复若干已知问题，提升软件稳定性。
